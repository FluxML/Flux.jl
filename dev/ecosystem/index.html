The Julia Ecosystem around Flux

These Julia packages provide models and tools for working with Flux. To suggest a package, open a pull request. See also academic work citing Flux or citing Zygote.

Flux models

  • Metalhead.jl provides pretrained vision, language and image generation models for Flux.

Computer vision

  • ObjectDetector.jl provides ready-to-go image detection via YOLO.

Natural language processing

  • TextAnalysis.jl provides several NLP algorithms that use Flux models under the hood.

Reinforcement learning

  • AlphaZero.jl provides a generic, simple and fast implementation of DeepMind's AlphaZero algorithm.

Graph learning

  • GraphNeuralNetworks.jl provides graph neural network layers for Flux.

Robust networks

  • RobustNeuralNetworks.jl includes classes of neural networks that are constructed to naturally satisfy robustness constraints.

Recurrent neural networks

  • RecurrentLayers.jl offers a collection of recurrent neural network layers.

Tools closely associated with Flux

High-level training flows

  • Ignite.jl is a Julia port of the Python library ignite for simplifying neural network training and validation loops, using events and handlers.
  • Tsunami.jl adds high-level ways to control training, parameter schedules and logging, inspired by PyTorch Lightning.

Datasets

  • HuggingFaceDatasets.jl loads datasets from the Hugging Face Hub, using the Python datasets package.
  • MLDatasets.jl provides access to benchmark datasets.

Data processing

  • DataAugmentation.jl provides augmentation pipelines for images, keypoints and segmentation masks.
  • HuggingFaceTokenizers.jl tokenizes text with pretrained Hugging Face tokenizers, using the Python tokenizers package.
  • MLUtils.jl provides tools for processing, splitting and batching datasets.

Parameters

  • ParameterSchedulers.jl provides schedules for learning rates and other training parameters.

Differentiable programming

  • DiffEqFlux.jl provides layers for neural differential equations. It can use Flux models through Lux's FromFluxAdaptor.
  • NeuralOperators.jl provides neural operators for learning maps between functions, such as PDE solution operators.
  • Yao.jl provides tools for simulating and differentiating quantum circuits.

Probabilistic programming

  • Turing.jl supports probabilistic programming and Bayesian inference in Julia.

Simulation-based inference

  • NeuralEstimators.jl enables amortized simulation-based inference using neural networks built with Flux.

Statistics

  • OnlineStats.jl provides single-pass algorithms for statistics.

Useful miscellaneous packages

  • Mill.jl helps to prototype flexible multi-instance learning models.
  • ValueHistories.jl provides data structures for tracking learning curves and other optimisation information.
  • InvertibleNetworks.jl provides building blocks for invertible neural networks.
  • ProgressMeter.jl provides progress meters for long-running computations.
  • TensorBoardLogger.jl logs training metrics to TensorBoard.
  • ArgParse.jl provides tools for parsing command-line arguments.
  • Parameters.jl provides types with default field values, keyword constructors and unpacking macros.
  • DataFrames.jl provides in-memory tabular data structures.
  • DrWatson.jl provides tools for managing scientific projects.

Alternatives to Flux

  • SimpleChains.jl focuses on fast execution for small neural networks on the CPU.
  • Lux.jl represents a model, its parameters and its state separately.
