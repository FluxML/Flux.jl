Models and Examples

Pretrained models with Metalhead.jl

Metalhead.jl provides pretrained Flux models for vision, language and image generation. Install Metalhead 0.10 or later with ] add Metalhead, then load an ImageNet-pretrained ResNet.

using Metalhead

model = create_model("timm/resnet50.a1_in1k")

Browse the Metalhead model catalog for architectures and checkpoints. For image preprocessing, inference and transfer learning, follow the Metalhead vision tutorial.

End-to-end training

  • ResNet-18 on TinyImageNet trains an image classifier and validates it on held-out images.
  • GPT-2 pretraining includes gradient accumulation, mixed precision and checkpointing.

Both examples include a Flux implementation using Reactant to compile the training step.

Older examples

The Flux model zoo collects earlier community examples, including examples written for older versions of Flux.
